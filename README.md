# Frontend Mentor - Blog Preview Card

This is my solution to the [Blog preview card challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS). The goal of the project was to build a simple, responsive blog preview card as closely as possible to the provided design.

## Overview

### The Challenge

Users should be able to:

- View the blog preview card at a comfortable size on the page
- See a clean card layout with an image, category label, title, description, and author section
- See hover and focus states for interactive elements

### What I Learned

This project helped me practise the basics of building a card component with HTML and CSS.

Some of the main things I worked on were:

- Using Flexbox to center the card on the page
- Creating a solid card shadow with `box-shadow`
- Adjusting padding and spacing inside small elements like the category label
- Structuring the card into clear sections: image, content, and author
- Matching colors, border radius, and spacing to a design reference

One thing I found useful was thinking of padding like space inside a box. It helped me understand how to control the amount of space around the text inside the "Learning" label.

### Continued Development
